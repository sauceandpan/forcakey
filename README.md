# Valentine Ask

This is a static Valentine page ready to deploy on Vercel.

## Deployment steps

1. Install Vercel CLI if needed:
   ```bash
   npm install -g vercel
   ```

2. Open a terminal in this folder:
   ```bash
   cd "c:\Users\rayan\Downloads\Do you wanna be my girl\valentine-ask-main\valentine-ask-main"
   ```

3. Deploy to Vercel:
   ```bash
   vercel
   ```

4. If you want to deploy directly to production after linking:
   ```bash
   vercel --prod
   ```

## Notes

- `vercel.json` is already configured for a static site.
- Your site entry point is `index.html`.
- All assets like `style.css`, `script.js`, and image files are served from this folder.
